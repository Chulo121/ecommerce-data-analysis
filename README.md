# 电商数据分析项目集 📊

本仓库收录了我在学习数据分析过程中完成的一系列**电商相关**数据分析项目，涵盖销售数据分析、用户画像与聚类、文本情感分析、机器学习预测建模等方向。

> **说明**：本仓库中的项目均基于网络上的开源数据分析项目进行学习与二次修改（调整分析思路、补充可视化、重写部分代码逻辑等），用于个人学习与技术积累，仅作学习交流使用，不涉及商业用途。如涉及原作者权益，欢迎联系删除或补充署名。

## 🛠 技术栈

- **数据处理**：Python、Pandas、NumPy
- **数据可视化**：Matplotlib、Pyecharts
- **机器学习**：Scikit-learn（KMeans 聚类、逻辑回归、线性回归）
- **文本分析**：中文分词（Jieba）、关键词提取、情感分析、词云（WordCloud）
- **开发环境**：Jupyter Notebook

## 📦 数据说明

- 各子项目目录下附带了对应的原始/样例数据文件（CSV、Excel 等），可直接运行 Notebook 复现分析过程。
- `e-commerce美妆/销售数据/` 目录下的月度交易原始数据体积较大（单月 400MB+），已压缩为 `.zip` 格式存放，使用前请自行解压。

## 📌 使用方式

```bash
# 克隆仓库
git clone https://github.com/Chulo121/ecommerce-data-analysis.git

# 安装依赖（按需，各子项目依赖略有不同）
pip install pandas numpy matplotlib pyecharts scikit-learn jieba wordcloud jupyter

# 进入对应子项目目录，启动 Jupyter 运行 .ipynb 文件
jupyter notebook
```
